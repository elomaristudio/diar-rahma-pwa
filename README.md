# Diar Rahma PWA v5

نسخة تجريبية من البوابة الرقمية ودفتر مجمع ديار الرحمة.

## ما الجديد في v5
- مركز إشعارات داخل التطبيق.
- عداد للإشعارات غير المقروءة.
- الإدارة/المكلفون يمكنهم إنشاء إشعار من داخل التطبيق.
- السكان يمكنهم فتح الإشعار وتعليمه كمقروء.
- أضيفت جداول notification_reads و push_subscriptions في Supabase.
- تم تجهيز تخزين الوثائق المركزي وصلاحياته في Supabase.

## ملاحظة مهمة حول Push
مركز الإشعارات الداخلي يعمل من قاعدة البيانات. الإشعارات التي تظهر كتنبيه حقيقي في شريط إشعارات الهاتف عند إغلاق التطبيق تحتاج مرحلة إضافية: إعداد Web Push/FCM أو مزود Push، ومفتاح VAPID/أسرار خادمية لا توضع داخل التطبيق.

## المصدر
- Blogger: الإعلانات والمحتوى العام.
- Supabase residential-hub: الحسابات، المصاريف، الإصلاحات، الوثائق والإشعارات.
